# 1소스 멀티유즈 캡션 워크플로

메인 세션이 총괄 PD로서 아래 순서로 진행한다.

## 1. 입력 확인 (부족하면 한 번에 모아서 질문)
- 영상/사진 내용: 무슨 반, 무슨 곡/안무, 몇 명, 무슨 상황
- 이번 게시물의 목적: 인지 / 신뢰 / 모집(무엇을, 언제까지)
- 나오는 학생 이름 (블로그 A형에 쓸 경우)
- 올릴 채널 (기본: 전부, 당근은 적합할 때만, 블로그는 사진이 여러 장이거나 학부모 대상일 때)

## 2. 채널캡션팀 병렬 호출
아래 서브에이전트를 **한 메시지에서 동시에** 호출한다. 각 프롬프트에 입력 내용과 저장 경로를 그대로 넘긴다.
- `caption-naver-blog`, `caption-naver-clip`, `caption-smartplace`, `caption-instagram`, `caption-tiktok`, `caption-daangn`, `caption-youtube`
- 저장 경로: `content/YYYY-MM-DD_<주제>/<채널>.md`
- 모집 목적이 아니면 `caption-smartplace`는 "플레이스 소식으로 올릴 가치가 있을 때만" 작성하도록 지시.

## 3. 검수
`compliance-checker`에게 해당 폴더 전체를 검수시킨다. "수정 후 통과"면 수정 반영까지 시킨다.

## 4. 결과 전달
- 폴더 경로와 함께, 채널별로 **바로 복사할 최종 문구**를 요약해 보여 준다.
- 원장님 확인 필요 사항(`[확인필요]` 등)을 맨 위에 모아 보여 준다.
