# 홍보영상 워크플로

메인 세션이 총괄 PD로서 진행한다.

## 1. 브리프
- 어떤 영상인지: `docs/promo-video-catalog.md` 번호 또는 설명
- 대상 반·목적·마감일 (없으면 메뉴판 기본값)
- 이미 찍어 둔 영상이 있으면 파일명·장면 목록
- 저장 폴더: `content/YYYY-MM-DD_<주제>/`

## 2. 기획 — `promo-video-producer`
기획안·콘티·촬영 목록 → `promo-video.md`

## 3. 편집 준비 — `video-editor`
기획안을 넘겨 편집 지시서와 자막 파일 → `edit-guide.md`, `subtitles.srt`
(촬영 전이면 콘티 기준으로 미리 만들고, 촬영 후 실제 클립 목록을 받아 다시 맞춘다.)

## 4. 검수 — `compliance-checker`
화면 자막·나레이션·엔딩 카드의 사실·과장·교습비 표시·음원 규칙 검수.

## 5. 업로드 문구 — 채널캡션팀 (선택)
영상이 완성되면 `one-source`처럼 채널별 캡션 에이전트를 병렬 호출해 업로드 문구를 만든다.

## 6. 전달
원장님께 한 화면 요약: 촬영 목록(장소별), 편집 순서 핵심, 자막 파일 위치, 확인 필요 사항.
