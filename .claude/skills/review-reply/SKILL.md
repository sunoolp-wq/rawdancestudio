# 리뷰·문의 응대 워크플로

1. 붙여넣은 내용을 분류한다: 리뷰 / 댓글 / 문의(DM·톡·채팅).
2. 리뷰·댓글 → `review-manager`, 문의 → `inquiry-concierge` 호출. 여러 건이면 병렬 호출.
3. 부정 리뷰 또는 교습비·환불·사고 관련이면 `compliance-checker`로 한 번 더 검수.
4. 건별로 바로 복사할 답변(A/B)을 보여 준다. 원장님이 내부 확인해야 할 사항은 따로 표시한다.
