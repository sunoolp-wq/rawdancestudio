# 주간 콘텐츠 워크플로

메인 세션이 총괄 PD로서 진행한다. 각 단계 결과 파일을 다음 단계 에이전트에게 경로로 넘긴다.

## 0. 입력
- 이번 주 목표(있으면): 예) 토요일 K-POP반 모집, 전문반 상담 5건
- 촬영 가능 일정·반, 특별 일정(발표회, 오디션, 휴원)
- 지난주 리포트가 있으면 `content/reports/`에서 자동으로 참조

## 1. 리서치 — `trend-researcher`
이번 주 챌린지 TOP 3, 다가오는 입시·오디션 일정, 키워드 → `content/research/YYYY-MM-DD.md`

## 2. 계획 — `campaign-strategist`
리서치 + 지난 리포트 + 목표로 주간 캘린더 → `content/plans/YYYY-Www.md`

## 3. 숏폼 기획 — `shortform-planner`
캘린더의 숏폼 항목별 훅·구성·채널 변형안 → 계획 파일 옆에 `content/plans/YYYY-Www_shortform.md`

## 4. 촬영 가이드 — `shoot-director`
몰아찍기 샷리스트 → `content/plans/YYYY-Www_shoot.md` (원장님·강사님 공유용)

## 5. 캡션 — 채널캡션팀 (병렬)
캘린더 항목별로 해당 채널 캡션 에이전트를 동시에 호출 → `content/YYYY-MM-DD_<주제>/<채널>.md`
촬영 전이라 영상이 없으면 "가안"으로 작성하고, 촬영 후 `one-source`로 다듬는다.

## 6. 검수 — `compliance-checker`
이번 주 생성 파일 전체 검수 및 수정.

## 7. 보고
원장님께 한 화면 요약: 이번 주 목표 / 요일별 업로드표 / 촬영 요청 목록 / 확인 필요 사항.
