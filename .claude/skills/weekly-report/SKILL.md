# 주간 리포트 워크플로

1. 지표를 받는다. 없으면 아래 표를 채워 달라고 요청한다.
   ```
   | 채널 | 게시물 수 | 조회/도달 | 공유 | 저장 | 문의 |
   | 인스타 | | | | | |
   | 틱톡 | | | | | |
   | 유튜브 쇼츠/롱폼 | | | | | |
   | 네이버 클립 | | | | | |
   | 스마트플레이스 (전화/예약/길찾기) | | | | | |
   | 당근 | | | | | |
   이번 주 문의 __건 / 체험 __건 / 등록 __건 / 문의 출처: __
   ```
2. `performance-analyst`를 호출해 `content/reports/YYYY-Www.md`를 작성한다.
3. 리포트의 "다음 주 실험"을 원장님께 요약하고, 원하면 바로 `weekly-content`로 이어서 다음 주 계획에 반영한다.
