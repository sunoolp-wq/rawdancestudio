## 글 구조 (위에서 아래 순서 고정)
1. **학원 헤더**
   - [확인필요: 현재 헤더 이미지/문구 그대로. 예) RAW DANCE STUDIO SUWON 로고 + 한 줄 소개]
2. **본문 (이번 글의 주제)**
   - 수업 후기 / 월말평가 / 내방 오디션 / 버스킹·공연 / 모집 안내 / 시간표 안내 중 하나
   - 사진·GIF 사이사이에 2~4줄 설명
3. **GIF**
   - 수업·안무 장면 GIF [확인필요: 위치 — 본문 중간 몇 개 / 하단 고정 GIF 여부]
4. **강사·클래스 정보**
   - 이번 글과 관련된 강사, 반 이름, 요일·시간, 교습비 (`brand/brand-guide.md` 값 그대로)

- 제목: 검색어를 앞에. 예) "수원역 댄스학원 | 유아 K-POP 토요일반 수업 현장 (로우댄스 수원점)"

- 실제 사진·GIF가 들어갈 자리는 `[사진: 설명]`, `[GIF: 설명]`으로 표시한다.
