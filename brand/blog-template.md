# 네이버 블로그 고정 양식 (blog.naver.com/rawdance_suwon)

## 글 종류
| 종류 | 언제 | 목적 |
|---|---|---|
| A. 수업 영상 글 | 수업 영상 업로드할 때 (가장 많이 씀) | 반 소개 + 영상, 기존 검색 유입 |
| B. 시간표·공지 글 | 월초 시간표, 휴원, 모집, 내방 오디션 공지 | 정보 전달 |
| C. 유입용 정보 글 | 주 1회 목표 | 학부모·학생이 **검색하는 질문**에 답해서 새 유입 만들기 |
| D. 현장 기록 글 | 행사·버스킹·월말평가·내방 오디션·학원 일상이 있을 때 (2026-10-14 대표님 지시로 추가) | "이 학원은 이런 일을 한다"는 신뢰. 사람들이 보고 오게 만드는 자료 |

공통 규칙
- **모바일 줄바꿈 (2026-10-14 원장님 요청):** 본문은 가운데 정렬 기준으로 **한 줄 15~20자**, 문장을 구절 단위로 끊는다. 단락 사이 빈 줄 1개, 마무리 문단 앞뒤는 빈 줄 2~3개 (기존 글과 같음).
- **표기 규칙 (붙여넣기 페이지용, `tools/blog_copy_page.py`):** 맨 위 헤더는 `<<소제목>>텍스트`, 구분선 자리는 `[구분선]` 한 줄, 사진 설명은 사진 자리 바로 아래 `(사진 설명) …`. 구분선은 기존 글처럼 헤더·대표 사진 다음 / 큰 단락 사이 / 고정 블록 앞 / 시간표 앞 / 지도 앞에 둔다.
- 네이버 지도는 고정 블록 안 1곳만 (따로 또 넣지 않음).
- 완성본은 `python3 tools/blog_copy_page.py content/<폴더>/naver-blog.md`로 붙여넣기 페이지를 만든다 (글꼴 나눔다시시작해·가운데·굵게).
- 네이버 에디터에서 복사할 때 섞여 들어오는 "AI 활용 설정", "사진 설명을 입력하세요" 같은 문구는 넣지 않는다.
- 이모지는 **고정 블록에 있는 것(✅ 📍 ⏰ 📞 💬 ☎)과 본문 마무리 1개(😊)까지만**. 그 외 본문에는 추가하지 않는다.
- 재원생은 모두 입회 시 초상권 동의서를 받았으므로 학생 이름·얼굴은 그대로 쓴다. 학교명은 쓰지 않는다.
- "내한 오디션"이 아니라 **"내방 오디션"**으로 쓴다 (내한 = 외국에서 한국에 옴).

## C. 유입용 정보 글 (신규)
학부모·학생이 네이버에 **실제로 검색하는 질문**에 답하는 글. 학원 홍보는 마지막에 짧게.

### 구조
```
제목: {검색 질문 그대로} | 수원 댄스학원 로우댄스 수원점
  예) 유아 K-POP 댄스 몇 살부터 시작할 수 있을까요? | 수원 댄스학원 로우댄스 수원점

1. 첫 3줄 안에 질문에 대한 짧은 답
2. 소제목 3~4개로 자세한 설명 (각 3~5줄, 실제 수업 사진·영상 사이사이)
3. "로우댄스 수원점에서는" 한 문단: 관련 반, 요일·시간, 교습비, 체험 여부 (사실만)
4. 공통 고정 블록
```
### 원칙
- 학원 실제 경험(수업 장면, 강사 코멘트)을 꼭 넣는다. 다른 사이트 글을 짜깁기하지 않는다.
- 같은 키워드를 억지로 반복하지 않는다. 제목 1회, 본문 자연스럽게 2~3회.
- 다른 학원과 비교하거나 깎아내리지 않는다.
- 주제 후보는 `docs/blog-topics.md`.

## D. 현장 기록 글 (신규, 2026-10-14)
학원 안팎에서 있었던 일을 **일기처럼** 남기는 글. RAW 의정부 블로그의 RAW NEWS 글(행사 공연·관람·출강 후기)을 본보기로 삼았다.

### 소재와 표현
| 소재 | 제목 예시 | 꼭 지킬 것 |
|---|---|---|
| 행사 **관람** (수원 예술제·피드백·무승부) | `<{행사명}> 로우댄스 수원점 친구들과 관람하고 왔어요` | **관람만 했다.** "공연했다·출전했다·참가했다·무대에 섰다" 금지. 다른 팀 이름·순위 쓰지 않음 |
| 게스트 공연 (Fl.RAW 버스킹 등) | `로우댄스 수원점 전문반 게스트팀 Fl.RAW(플로우) {장소} 버스킹 공연 후기` | "게스트팀으로 참여"라고 정확히. 주최가 우리가 아니면 주최 이름을 씀 |
| 월말평가 | `로우댄스 수원점 {M}월 월말평가 현장 \| {반}` | 순위를 쓰면 원장님이 준 결과 그대로 |
| 기획사 내방 오디션 | `로우댄스 수원점 {기획사} 내방 오디션 현장` | 합격·결과는 확인된 것만. 기획사 로고·심사위원 얼굴은 기획사 공개 동의가 있을 때만 |
| 학원 일상 | `로우댄스 수원점 {상황} 하는 날` (예: 월말평가 끝나고 피자 파티) | 짧아도 됨 (600자 이상) |

### 원칙
- **본 것, 한 것, 들은 것만 쓴다.** 날짜·장소·인원·학생 말은 원장님이 알려 준 그대로. 모르면 `[확인필요: ...]`.
- 분량 800~1,300자 (고정 블록 제외), 사진 4~12장.
- 다른 학원·외부 학생 얼굴이 보이는 사진은 쓰지 않는다 (우리 초상권 동의서 대상이 아님). 무대는 멀리서 찍은 전경, 우리 학생은 객석·대기·단체 사진으로.
- 이모지는 고정 블록 것 + 본문 2~3개까지 (현장 글은 A~C형보다 조금 더 허용).
- 메인 키워드는 행사명·소재명이 제목 앞에 오도록 한다. "수원댄스학원"을 제목 맨 앞에 두지 않는다 (기존 43편과 경쟁 방지).
- 해시태그는 고정 해시태그 중 5~8개 + 행사명 태그 1~2개.
