# 온라인 RAW 연습실 공개 버전 만들기 (로그인 없이 애들끼리 서로 보이게)

구성: **Firebase**(무료, 접속한 사람 위치를 실시간으로 주고받는 곳) + **Netlify**(무료, 페이지를 올려 두는 곳)
원장님이 할 일은 1단계(Firebase 5분)와 3단계(올리기 1분)뿐이에요. 2단계는 제가 해요.

---

## 1단계. Firebase 만들기 (구글 계정, 약 5분)

1. https://console.firebase.google.com 접속 → 구글 로그인
2. **프로젝트 만들기**(또는 프로젝트 추가) → 이름 `raw-online` → 계속
   - Google 애널리틱스는 **사용 안 함**으로 끄고 → 프로젝트 만들기
3. 왼쪽 메뉴 **빌드 → Authentication** → 시작하기
   - **Sign-in method(로그인 방법)** 탭 → **익명** → 사용 설정 켜기 → 저장
   - (애들이 로그인하는 게 아니라, 기기마다 이름 없는 번호만 자동으로 받는 방식이에요)
4. 왼쪽 메뉴 **빌드 → Realtime Database** → 데이터베이스 만들기
   - 위치: **싱가포르 (asia-southeast1)** → 다음
   - **잠금 모드로 시작** → 사용 설정
5. Realtime Database 화면 위쪽 **규칙** 탭 → 안에 있는 글을 전부 지우고 아래 `firebase-rules.json` 내용을 그대로 붙여넣기 → **게시**
   - 이 규칙: 캐릭터 위치·닉네임·동작만 저장 가능, 자기 캐릭터만 고칠 수 있음, 그 밖의 건 저장 안 됨
6. 왼쪽 위 **톱니바퀴 → 프로젝트 설정** → 아래쪽 **내 앱**에서 웹 아이콘 **`</>`** 클릭
   - 앱 닉네임 `raw-online` → (Firebase 호스팅 체크는 안 해도 됨) → 앱 등록
   - 화면에 나오는 `const firebaseConfig = { ... };` 부분을 **통째로 복사해서 저한테 보내 주세요**
   - 이 값은 비밀번호가 아니에요. 원래 페이지 안에 들어가는 공개용 주소라 채팅으로 보내도 괜찮아요.

## 2단계. 제가 할 일

- 보내 주신 설정을 넣어서 공개용 파일(`web/index.html`)을 만들고 테스트한 뒤 파일로 보내 드려요.

## 3단계. Netlify에 올리기 (컴퓨터에서 1분)

1. 바탕화면에 새 폴더 `raw-online` 만들고, 제가 보낸 `index.html`을 그 안에 넣기
2. https://app.netlify.com/drop 접속 → 구글로 가입/로그인
3. `raw-online` **폴더를 통째로** 화면에 끌어다 놓기 → 몇 초 뒤 주소가 생겨요 (예: `https://○○○.netlify.app`)
4. **Site configuration → Change site name**에서 이름을 `raw-suwon-online` 처럼 바꾸면 주소가 깔끔해져요
5. 그 주소를 단톡방에 올리면 끝. 애들은 링크만 누르면 바로 들어와요 (앱 설치·로그인 없음)

나중에 고칠 게 생기면: 제가 새 `index.html`을 드리면 Netlify 사이트의 **Deploys** 탭에 폴더를 다시 끌어다 놓으면 돼요.

## 알아 둘 것

- **무료 한도:** 동시에 100명까지 접속할 수 있어요. 데이터 사용량도 우리 학원 규모로는 무료 범위 안이에요.
- **개인정보:** 이름·학교·사진은 안 받아요. 닉네임은 "그루브 타는 루키"처럼 자동으로 정해지고, 애들이 직접 글자를 쳐서 다른 사람에게 보여 줄 수 있는 칸은 없어요 (소원 쪽지는 자기 폰에만 보여요).
- **아무것도 쌓이지 않아요:** 페이지를 닫으면 그 캐릭터는 바로 지워져요.
- 링크를 아는 사람은 누구나 들어올 수 있으니, 학원 단톡방 같은 곳에만 올려 주세요.
