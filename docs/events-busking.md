# 버스킹·지역 행사 출연 경로 (2026-10-11 조사)

> 공고는 해마다 바뀐다. 아래 "다음 공고 예상 시기"는 2025~2026년 공고 기준 추정이며, 확정 일정은 각 기관 공지로 확인한다.

## 1. 스타필드 수원 (장안구 정자동)
- **공개 모집 공고는 확인되지 않음.** 사유지라 허가 없는 버스킹은 불가.
- 지금까지 열린 공연: 별마당 도서관 월 1회 토요일 공연, 별마당 태권도·치어리딩 공연, 타워 아트리움 아이돌 버스킹(2025), 개점 1주년 축제.
- **경로 = 제안(피칭)**: 스타필드 수원 대표 고객센터 → 이벤트·마케팅 담당 연결 요청 / 공식 인스타그램 DM / 신세계프라퍼티 제휴 문의.
- 제안 타이밍: 시즌 행사(크리스마스·연말, 개점 기념일, 가정의 달, 방학) **2~3개월 전**.
- 준비물: 1장짜리 제안서 + 공연 영상 링크(2~3분 하이라이트) + 팀 구성·공연 시간(15~30분)·필요 장비.

- 2025년 거리공연 조건(참고): 소음 75dB 이하, 20시 이후 공연 금지, 1일 1장소 3~5팀·팀당 30분 내외.
- 공공 행사는 **상업 홍보(학원 모집 문구·교습비 안내) 제한**이 있을 수 있다. 신청은 학원 이름보다 **팀 이름(예: Fl.RAW)** 으로, 소개에 "로우댄스학원 수원점 소속"을 넣는 정도가 안전.

## 3. 준비해 둘 것 (공고 나오면 바로 신청)
1. 공연 영상 포트폴리오: 유튜브 재생목록(버스킹·월말평가·정기공연) + 2~3분 하이라이트 1개
2. 팀 소개서 1장: 팀명, 인원, 장르, 공연 길이, 셋리스트, 필요 장비(스피커 보유 여부)
3. 보호자 동의: 행사 출연·촬영 동의 (입회 동의서 범위에 외부 공연이 포함되는지 확인)
4. 음원: 공공 행사는 음원 저작권 처리 주체 확인 (주최 측 처리 여부)
