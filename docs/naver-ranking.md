# 네이버 검색(플레이스) 순위 올리기 전략 (2026-10-13)

> 네이버는 플레이스 순위 공식을 공개하지 않는다. 아래는 업계 분석에서 공통으로 나오는 틀(적합도·인기도·신뢰도 + 거리)을 정리한 **가설**이며, 매주 스마트플레이스 통계로 검증한다.
> 기준 문서: `content/2026-10-08_smartplace-audit/smartplace.md` (점검표·소개글·대표 키워드 후보)

## 0. 먼저 알아둘 것
- **순위는 사람마다 다르게 보인다.** 같은 "수원 댄스학원"이라도 검색하는 사람의 위치(거리)에 따라 결과가 바뀐다. 광교·영통에서 검색하면 그 동네 학원이 위에 뜬다. 그래서 "모든 검색에서 1등"은 불가능하고, **목표 키워드를 정해 하나씩 1등을 만든다.**
- 2026.6 개점이라 리뷰·저장 같은 누적 신호가 적다. 처음 3~6개월은 경쟁이 약한 키워드부터 잡는다.

## 1. 목표 키워드 (단계별)
| 단계 | 키워드 | 이유 |
|---|---|---|
| 1단계 (먼저 1등) | 매교역 댄스학원, 수원역 댄스학원, 팔달구 댄스학원, 교동 댄스학원 | 학원 위치와 가장 가깝고 경쟁이 적음 |
| 2단계 | 수원 케이팝댄스, 수원 키즈댄스, 수원 유아댄스, 수원 오디션학원, 수원 실용무용 입시 | 반 특성으로 차별화되는 키워드 |
| 3단계 | 수원 댄스학원 | 가장 경쟁이 센 대표 키워드. 1·2단계 신호가 쌓인 뒤 |

### 대표키워드 5개 (2026-10-14 확정안)
| 순서 | 대표키워드 | 이유 |
|---|---|---|
| 1 | 수원댄스학원 | 원장님 지정. 가장 큰 키워드 |
| 2 | 매교역댄스학원 | 학원에서 가장 가까운 역(7번 출구 도보 약 10분). 인근 경쟁 학원(무브댄스 수원·센터댄스 수원점)은 수원역·갓매산로 쪽이라 이 키워드는 경쟁이 가장 약할 가능성 |
| 3 | 수원역댄스학원 | 수원역 생활권 검색 수요. 경쟁 학원이 있어 1위는 2번보다 어려움 |
| 4 | 수원케이팝댄스 | 우선 모집 K-POP반(유아·키즈·취미·토요일) 전체를 받는 키워드 |
| 5 | 수원실용무용입시 | 전문반·2028 입시반 모집용. 검색량은 작아도 검색하는 사람이 곧 상담 대상 |

- 예비 후보: 팔달구댄스학원(1위 가능성 높음, 검색량 작음), 수원키즈댄스(키즈 경쟁 학원 있음), 수원오디션학원.
- 확인된 근처 경쟁 학원 (웹 검색, 2026-10-14): 무브댄스학원 수원 (팔달구 갓매산로 51, K-POP·입시·오디션·키즈), 센터댄스학원 수원점 (팔달구), 레이댄스학원 (영통 매탄동), 오지댄스 (영통). 네이버 지도 직접 확인은 이 작업 환경에서 막혀 있어 원장님 확인 필요.
- 검색량은 네이버 검색광고 키워드 도구(searchad.naver.com → 도구 → 키워드 도구)에서 월간 검색수로 확인. 예비 후보와 비교해 검색수가 0에 가까운 키워드는 바꾼다.

## 2. 적합도 (등록 정보, 원장님이 오늘 할 수 있는 것)
- 스마트플레이스 점검표 H1~H7, M1~M5 먼저 완료.
- 업체명은 "로우댄스학원 수원점" 그대로. **업체명에 키워드를 붙이지 않는다** (네이버 정책 위반 소지, 노출 제한 위험).
- 대표 키워드는 점검표 2-4 후보 순서대로.
- 소개글·가격(메뉴)·사진·시간표에 목표 키워드가 자연스럽게 들어가게.
- 소식 주 1~2회 (최신성).

## 3. 인기도 (실제 사람의 행동, 꾸준히 쌓기)
| 신호 | 방법 | 담당 |
|---|---|---|
| 방문자 리뷰 | 재원생 학부모·성인 수강생에게 자연스럽게 요청. 한 번에 몰지 말고 **주 2~3건 흐름**으로. 리뷰 대가(선물·할인)는 주지 않는다. | `review-manager` 요청 문구 |
| 리뷰 답글 | 미답변 0건, 매번 다르게 | `review-manager` |
| 저장·알림받기 | 상담·체험 온 분에게 "플레이스 저장해 두시면 시간표 소식 받아보실 수 있어요" 안내 | `inquiry-concierge` |
| 블로그 리뷰 | 학원 블로그 글에 **네이버 지도(플레이스) 첨부** → 플레이스 블로그 리뷰 영역에 노출. C형 유입용 글 주 1개 (목표 키워드 제목) | `caption-naver-blog` |
| 클립 | 모든 네이버 클립에 장소(플레이스) 연결 | `caption-naver-clip` |
| 외부 유입 | 인스타 프로필·당근·카톡 채널에 네이버 플레이스 링크. 진짜 관심 있는 사람이 들어와 전화·길찾기·톡톡을 누르는 것이 가장 좋은 신호 | 각 채널 캡션팀 |

## 4. 하지 않는 것 (순위가 오히려 떨어지거나 제재)
- 트래픽 작업, 리워드(포인트)로 저장·클릭·길찾기 유도, "순위 보장" 대행사 상품.
- 리뷰 대행, 지인 몰아쓰기, 같은 문장 반복 리뷰. 가짜 후기는 표시광고법 위반 소지.
- 업체명·소개글에 키워드 도배, 실제 위치와 먼 지역명 키워드.

## 5. 빠른 길: 네이버 플레이스 광고
- 지역 키워드 검색 시 플레이스 영역 위쪽에 "광고" 표시로 노출. **클릭당 과금(CPC)**, 클릭이 없으면 비용 없음.
- 시작 권장: 하루 예산 1~2만 원 상한, 1단계·2단계 키워드부터, 2주 단위로 키워드별 클릭·문의 확인.
- 집중 시기: 방학 시작 2~3주 전, 신학기 2월 중순 (브랜드 가이드 시즌표).
- 광고는 자연 순위와 별개. 광고를 끄면 노출도 끝난다. 계속 남는 건 3번의 리뷰·저장·블로그 같은 신호다.

## 6. 측정
- 매주 월요일: 스마트플레이스 통계의 **유입 키워드 순위**, 전화·길찾기·톡톡 수 기록 → `performance-analyst`.
- 순위 확인은 학원이 아닌 장소(집 등)에서, 로그아웃 상태로 목표 키워드를 검색해 기록 (내 위치·검색 기록 영향 줄이기).
