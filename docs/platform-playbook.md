# 채널별 플레이북

> 노출 알고리즘은 대부분 공식 공개되지 않았습니다. 아래 "노출 요령"은 공식 발표와 업계 분석을 정리한 **가설**이며,
> 각 채널 인사이트 지표로 매주 검증합니다 (`performance-analyst`). 출처는 `docs/research.md` 참고.

## 한눈에 보는 채널 역할 (퍼널)
```
[알게 됨]  틱톡 · 인스타 릴스 · 유튜브 쇼츠 · 네이버 클립   ← 영상 1개를 채널별로 변형 (1소스 멀티유즈)
    │
[믿게 됨]  유튜브 롱폼 · 인스타 피드/하이라이트 · 스마트플레이스 리뷰
    │
[문의함]   스마트플레이스(전화·예약·길찾기) · 인스타 DM · 당근 채팅 · 카톡 채널
    │
[등록함]   체험 수업 → 상담 → 등록   (inquiry-concierge)
```

| 채널 | 주 타깃 | 역할 | 권장 빈도 |
|---|---|---|---|
| 네이버 클립 | 학부모, 네이버로 학원 찾는 사람 | 네이버 검색·플레이스 연결 숏폼 | 주 3~5회 |
| 네이버 스마트플레이스 | "수원 댄스학원" 검색자 | 최종 착지점: 소식·리뷰·예약·전화 | 소식 주 1~2회, 리뷰 답글 매일 |
| 인스타그램 | 10대 수강생, 지망생, 성인 | 브랜드 허브 + 릴스 신규 도달 + DM 상담 | 릴스 주 3~5회, 스토리 매일 |
| 틱톡 | 10대, 아이돌 지망생 | 챌린지·트렌드 도달, 검색형 숏폼 | 주 4~7회 |
| 당근 (스토리/소식) | 동네 학부모, 성인 취미 | 동네 인지도, 체험 쿠폰 | 월 2~4회 (시즌 집중) |
| 유튜브 | 입시생·학부모 (롱폼), 10대 (쇼츠) | 쇼츠 도달 + 롱폼 신뢰(입시·발표회·수업 풀버전) | 쇼츠 주 3회, 롱폼 월 2~4회 |

---

## 1. 네이버 클립
- **왜 중요한가:** 네이버 검색·홈피드에 노출되고, 2026년 네이버는 **플레이스 리뷰와 클립 연동**, 클립탭 개편을 발표했다. 장소 기반 콘텐츠(학원)에 유리한 흐름.
- **노출 요령 (가설)**
  - 1분 안팎, 첫 장면에 결과물(완성 안무·무대)을 먼저.
  - 클립 에디터의 **장소(플레이스) 연결 기능**으로 스마트플레이스를 꼭 붙인다.
  - 제목/본문에 검색어 그대로: "수원 댄스학원", "수원 키즈댄스", "실용무용 입시".
  - 이달의 해시태그 미션 등 네이버 공식 미션 참여 검토.
  - 영상 외 이미지+텍스트 게시물도 지원되므로 시간표·모집 안내는 이미지형으로도 활용.
- **캡션 구조:** 제목(검색 키워드 포함) → 본문 2~4줄(대상·위치·내용) → 행동 유도(플레이스에서 예약/전화) → 해시태그 5~10개.

## 2. 네이버 스마트플레이스
- **왜 중요한가:** 학부모가 "수원 댄스학원"을 검색하면 처음 보는 곳. 전화·예약·길찾기로 바로 이어지는 **전환 착지점**.
- **노출 요령 (업계 분석 기준)**
  - 정보 완성도: 운영시간, 교습비, 사진, 클래스 소개를 최신으로 유지. 방치된 플레이스는 밀린다는 분석이 많다.
  - 소식 주기적 업로드: 개강·특강·모집 마감·발표회.
  - 리뷰는 개수보다 **꾸준함과 진정성** (단기간 몰림·비슷한 문장 리뷰는 역효과). 리뷰 답글은 빠르게, 매번 다르게.
  - 사용자 행동(체류시간, 전화·예약 클릭)이 중요하다는 분석 → 사진·가격·시간표를 충실히.
- **소식 구조:** 제목(무엇을·언제) → 대상/일정/교습비/신청 방법 → 사진 3~5장 가이드 → 쿠폰/예약 연결.

## 3. 인스타그램
- **공식 확인된 핵심 신호 (2025.1 모세리):** 시청 시간, 도달 대비 좋아요, **도달 대비 공유(DM 전송)**. 공유는 비팔로워 도달에 특히 강하다는 분석.
- **노출 요령**
  - 첫 3초 훅. 끝까지 보게(반복 재생) 짧고 루프되는 편집.
  - "친구 태그/공유하고 싶은" 포인트: 챌린지 같이 하자, 입시 준비 체크리스트(저장 유도).
  - 릴스 = 비팔로워 도달, 피드/스토리 = 기존 팔로워 관계 → 스토리로 수업 일상·Q&A 스티커·투표.
  - 하이라이트: 시간표 / 교습비·상담 / 합격·무대 / 후기 / 오시는 길.
  - 해시태그는 3~5개로 핵심만 (과다 사용 지양).
- **캡션 구조:** 첫 줄 훅(피드에서 잘리기 전) → 2~4줄 스토리 → 행동 유도(DM 키워드, 예: "체험" DM) → 해시태그.

## 4. 틱톡
- **흐름:** 챌린지 플랫폼에서 **검색 플랫폼**으로 확장 중이라는 분석이 많다. 자막·화면 텍스트·음성 속 키워드가 검색 노출에 쓰인다는 주장.
- **노출 요령 (가설)**
  - 트렌드 음원·챌린지는 빠르게 (발견 후 며칠 안).
  - 화면 텍스트에 검색어를 자연스럽게: "실용무용 입시 준비", "오디션 안무 추천".
  - 반복 가능한 시리즈 포맷: "입시생의 하루", "오디션 전 1주일", "초보 vs 3개월 후".
  - 질문형 콘텐츠: "예고 실기 뭐 봐요?" 같은 질문에 답하는 영상.
  - 좋아요·팔로워 구매 등 인위적 부스팅 금지 (제재 위험).
- **캡션 구조:** 짧은 한 줄 + 검색 키워드 + 해시태그 3~6개.

## 5. 당근 (비즈프로필 소식 / 스토리)
- **역할:** 동네 이웃(학부모·성인)에게 노출. 소식은 비즈프로필 검색·동네지도 등에 노출될 수 있고 단골에게 전달된다.
- **활용:** 소식(개강·특강·발표회), 쿠폰(체험수업), 채팅(빠른 상담), 단골 관리.
- **요령:** 광고 티보다 **동네 이웃 말투**. "○○동 학부모님들~" 처럼 동네명 언급. 짧고 사진 위주. 운영시간·위치 정확히.
- 시즌(방학특강, 신학기) 직전에 집중 운영.

## 6. 유튜브
- **구조:** 쇼츠와 롱폼은 추천 시스템이 따로 움직인다는 분석이 다수 → 쇼츠는 도달, 롱폼은 신뢰·전환으로 역할 분리.
- **쇼츠:** 첫 장면 승부, 반복 재생 유도, 설명·고정댓글로 관련 롱폼 연결.
- **롱폼 아이디어:** 입시 실기 준비 가이드, 수업 풀버전/안무 튜토리얼, 발표회 풀영상, 합격생 인터뷰(동의 필수), 학원 투어.
- **주의:** 상업 음원은 Content ID로 차단·수익 제한 가능 → 유튜브 오디오 보관함 / 쇼츠 제공 음원 사용. 같은 영상 반복 업로드는 "재사용 콘텐츠"로 불리할 수 있음.
- **메타데이터 구조:** 제목(키워드 앞쪽) → 설명 첫 2줄(요약+위치) → 타임스탬프(롱폼) → 상담 링크 → 해시태그 3개 → 고정 댓글.
