# 리서치 요약 (2026-10 기준)

## 1. 로우댄스학원 (RAW DANCE STUDIO)
- 온라인에서 확인되는 곳은 **의정부 본점**(경기 의정부시 시민로 127 5층, 2022.4 개원).
- 유튜브 채널 소개 기준 포지셔닝: **입시·아이돌·키즈 오디션 전문, 실용무용 예고/예대 준비**.
- **수원점 정보(주소, 계정, 클래스)는 검색되지 않음** → `brand/brand-guide.md`에서 직접 채워야 함.
- 시사점: 수원점은 아직 온라인 존재감이 약한 상태로 보이며, "수원 + 입시/오디션/키즈" 검색어를 선점하는 것이 1순위 과제.

## 2. 수원 지역 경쟁 환경
- 팔달구 무용/댄스 학원은 학원 정보 사이트 기준 약 9곳 (발레 포함).
- 수원역·매산로 일대에 센터댄스(수원점), 무브댄스(수원) 등 입시·K-POP 댄스학원이 있음.
- 지역 내 합격 실적·수요 통계는 공개 자료 없음 → `trend-researcher`가 분기마다 경쟁 학원 채널을 관찰.

## 3. 채널별 동향
- **네이버 클립:** 2026.3 수익화 범위 확대(이미지+텍스트 게시물 포함), 유입처·시청시간 분석툴 추가 예고, AI 에디터(해시태그·음원 추천) 예정. 2026.4 플레이스 리뷰-클립 연동, 클립탭 개편 발표. 공식 랭킹 기준은 비공개.
- **스마트플레이스:** 업계 분석상 키워드 입력보다 이용자 행동(체류·전화·예약 클릭), 정보 완성도, 꾸준한 소식, 자연스러운 리뷰 흐름이 중요. 공식 기준은 비공개.
- **인스타그램:** 2025.1 모세리 공개 3대 신호 = 시청 시간, 도달 대비 좋아요, 도달 대비 공유(전송). 릴스는 비팔로워, 피드·스토리는 팔로워 관계 중심.
- **틱톡:** 검색 플랫폼화, 자막·화면 텍스트 기반 검색 노출이 강조됨(업계 주장). 챌린지는 여전히 인지도 수단.
- **유튜브:** 쇼츠·롱폼 추천 분리 분석 다수, 만족도 신호 중시. 상업 음원은 Content ID 리스크.
- **당근:** 비즈프로필(무료) 소식·쿠폰·채팅·단골 관리. 소식은 동네 검색·지도 등에 노출 가능.

## 4. 법·규정 체크 포인트 (최종 확인은 관할 교육청/법령 원문으로)
- 학원법: 인터넷 등으로 학습자 모집 광고 시 **교습비 표시 의무**, 허위 표시 시 행정처분 가능. 표시 방법은 시도교육청 기준.
- 표시광고법: 부대비용·환불 규정 등 중요정보 누락 시 과태료 사례(공정위).
- 미성년 수강생 사진·영상: 개인정보에 해당, 보호자 동의(용도·기간 명시) 필요.
