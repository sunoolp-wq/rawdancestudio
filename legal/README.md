# 법무팀 (마케팅 본부와 별도)

| 역할 | 에이전트 | 하는 일 |
|---|---|---|
| 사건접수 | `legal-intake` | 사실관계·타임라인·증거목록·질문 정리 |
| 리서치 | `legal-researcher` | 법령·판례 조사 (출처 링크 필수) |
| 수석변호사 | `legal-strategist` | 쟁점 지도, 승부처, 경로 비교, 협상 카드, 실행 계획 |
| 레드팀 | `legal-opposing-counsel` | 상대방 변호사 시점의 공격·반소·판사 질문 예측 |
| 서면 | `legal-drafter` | 내용증명, 조정신청서, 소장·답변서·준비서면, 가처분, 합의서 |
| 최종검수 | `legal-reviewer` | 판례·조문 실재 확인, 날짜·금액·기한·자백 검수 |

워크플로: `.claude/skills/legal-case/SKILL.md` ("퇴거 분쟁 사건 진행해줘" 등으로 시작)

## 보안
이 저장소는 공개 저장소다. 사건 자료는 `legal/cases/` 아래에만 두며, 이 경로는 `.gitignore`로 커밋되지 않는다.
