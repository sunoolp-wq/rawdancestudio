# RAW 영상공장 (원장님 맥용, 2026-11-17)

매번 Claude에게 부탁하던 반복 영상 작업을 원장님 맥에서 직접 돌리는 프로그램. 인터넷 창(크롬)에서 칸만 채우고 [만들기].

| 탭 | 하는 일 | 원래 쓰던 도구 |
|---|---|---|
| 스토리 시간표 | 날짜 고르면 '오늘의 수업' 15초 스토리 (토·일 제외). 대강·팝업·휴강은 날짜별 표에서 바꾸고 저장 | `tools/daily-story/render.js` |
| 쌤 15초 | 수업 영상 → 쌤 따라가며 세로로 → RAW 스타일 이름·장르·요일 + 끝 화면 | `follow_yolo.py` → `make_reel2.js` |
| TRACKPAD 릴스 | 풀 안무 쌤 따라가기 + 앞부분 TRACKPAD 자막(곡명/강사/장르). 음원을 넣으면 연습실 소리에 맞춰 깨끗한 음원으로 | `follow_yolo.py` → `music_sync.py` → `add_title.js` |
| 음원 싱크 | 영상 속 연습실 소리와 음원을 비교해 정확한 위치에 음원 입히기 | `tools/class-reel/music_sync.py` |
| LUT | 완성 영상에 색감 LUT만 (강도 %). LUT는 `tools/raw-studio/luts/`에 .cube 파일을 넣으면 목록에 나옴 | ffmpeg lut3d |

쌤 15초·TRACKPAD·음원 싱크에도 LUT를 같이 고를 수 있음 (자막 넣기 전에 영상에만 입힘).

## 처음 설치 (한 번만, 10~20분)
1. GitHub 저장소 `sunoolp-wq/rawdancestudio` → 브랜치 `claude/low-dance-marketing-agents-lisndi` → 초록 [Code] → **Download ZIP** → 압축 풀기 (예: `문서/rawdancestudio`)
2. 폴더 안 **`1_설치하기.command`** 더블클릭
   - "확인되지 않은 개발자" 경고가 뜨면: 파일 **오른쪽 클릭 → 열기 → 열기**
   - 맥 비밀번호를 물으면 입력 (쳐도 화면에 안 보이는 게 정상)
3. "✅ 설치 끝!"이 나오면 창 닫기

## 쓸 때
1. **`2_RAW영상공장_열기.command`** 더블클릭 → 브라우저에 화면이 뜸. 검은 창은 쓰는 동안 켜 두기 (닫으면 멈춤)
2. 탭 고르기 → 영상 끌어다 놓기 → 칸 채우기 → [만들기]
3. 오른쪽 '작업'에 진행 상황 → 끝나면 바로 미리보기 + [파인더에서 보기]
4. 결과: `동영상(Movies)/RAW 영상공장/날짜/` (확인 사진 포함). 올린 원본 복사본은 `.작업중` 폴더 (가끔 비워도 됨)

## 쌤 고르기 (단체 수업)
- 영상을 올리면 장면 사진이 나옴 → 슬라이더로 장면 옮기기 → **쌤을 클릭**(보라 동그라미)
- [이 장면을 시작으로]를 누르면 그 시각이 시작 초가 됨
- 결과와 같이 나오는 **확인 사진**에서 보라 상자가 계속 쌤인지 확인. 다른 사람이면 쌤이 혼자 잘 보이는 장면에서 다시 클릭
- 세로 영상(원장님이 편집한 세로본 등)은 따라가기 없이 그 구간만 씀

## 음원 싱크가 "못 찾았어요"라고 할 때
- 영상 속 소리가 다른 노래거나(다른 홀 소리 등) 음원 버전이 다를 때 (스피드업·리믹스)
- 같은 노래를 여러 번 튼 긴 영상 → '쓸 구간 시작·끝'을 넣으면 그 안에서만 찾음
- 그래도 안 되면 '노래 0:00 = 영상 몇 초'를 직접 입력 (노래 첫 소리가 나오는 순간의 영상 시각)

## 시간이 걸리는 정도 (맥 M 시리즈 기준 예상)
- 스토리 1개: 30초~1분 · 쌤 15초 (4K): 2~5분 · TRACKPAD 30초 (4K): 4~8분
- 하나씩 차례로 만듦. 여러 개 눌러 두면 줄 서서 차례로

## 업데이트
- **`3_업데이트.command`** 더블클릭 → 최신 버전 받기
  - 처음 한 번만 GitHub 로그인: 화면의 8자리 코드 복사 → 엔터 → 브라우저에서 붙여 넣고 승인
  - 원장님이 화면에서 바꾼 대강·팝업은 합쳐서 보존 (같은 날짜는 원장님 것 우선). 설치물·결과 영상은 그대로
  - 프로그램이 켜져 있었다면 검은 창 닫고 `2_RAW영상공장_열기.command` 다시 실행

## 만든 사람 메모 (Claude용)
- 서버 `server.py`(Flask, 127.0.0.1:5577) + 화면 `index.html`. 작업은 한 줄 큐로 순서대로. 결과 폴더는 환경 변수 `RAW_OUT`로 바꿀 수 있음
- 맥 설치: Homebrew → node·ffmpeg·uv → `.venv` = uv가 받은 파이썬 3.12(`uv venv --managed-python`, Homebrew 파이썬은 macOS 26.2에서 맥 버전을 못 읽어 pip이 멈춤) + ultralytics, lap, flask, numpy → `npm install`(playwright) + `npx playwright install chromium` → `tools/fonts/install.sh`(맥은 ~/Library/Fonts)
- 스토리는 기존대로 `content/날짜_daily-story/story.mp4`를 만들고 결과 폴더로 복사. 대강·팝업은 `tools/daily-story/extra.json`에 저장 → 원장님 맥의 extra.json은 저장소와 따로 놀 수 있음 (Claude에게 부탁할 땐 바뀐 내용 알려 주기)
