# RAW 영상공장 (원장님 맥용, 2026-11-17)

매번 Claude에게 부탁하던 반복 영상 작업을 원장님 맥에서 직접 돌리는 프로그램. 인터넷 창(크롬)에서 칸만 채우고 [만들기].

| 탭 | 하는 일 | 원래 쓰던 도구 |
|---|---|---|
| 스토리 시간표 | 날짜 고르면 '오늘의 수업' 15초 스토리 (토·일 제외). 대강·팝업·휴강은 날짜별 표에서 바꾸고 저장 | `tools/daily-story/render.js` |
| 쌤 15초 | 수업 영상 → 쌤 따라가며 세로로 → RAW 스타일 이름·장르·요일 + 끝 화면 | `follow_yolo.py` → `make_reel2.js` |
| TRACKPAD 릴스 | 춤 시작 전 1~5초 TRACKPAD 자막(곡명/강사/장르) → 풀 안무 쌤 따라가기 → 끝 RAW 로고 2.5초(음악은 이어짐). 음원은 연습실 소리에 맞춰 깨끗한 음원으로 | `follow_yolo.py` → `music_sync.py` → `add_title.js` |
| 음원 싱크 | 영상 속 연습실 소리와 음원을 비교해 정확한 위치에 음원 입히기 | `tools/class-reel/music_sync.py` |
| 유튜브 이어붙이기 | 같은 곡·같은 구간 A그룹 → B그룹 → 쌤 솔로 → 단체를 가로 그대로 이어 붙임. 영상마다 깨끗한 음원, 사이는 교차 디졸브(0.5·1초) 또는 컷 | `tools/class-reel/yt_concat.py` |
| LUT | 완성 영상에 색감 LUT만 (강도 %). LUT는 `tools/raw-studio/luts/`에 .cube 파일을 넣으면 목록에 나옴 | ffmpeg lut3d |

쌤 15초·TRACKPAD·음원 싱크에도 LUT를 같이 고를 수 있음 (자막 넣기 전에 영상에만 입힘).

## 처음 설치 (한 번만, 10~20분)
1. GitHub 저장소 `sunoolp-wq/rawdancestudio` → 브랜치 `claude/low-dance-marketing-agents-lisndi` → 초록 [Code] → **Download ZIP** → 압축 풀기 (예: `문서/rawdancestudio`)
2. 폴더 안 **`1_설치하기.command`** 더블클릭
   - "확인되지 않은 개발자" 경고가 뜨면: 파일 **오른쪽 클릭 → 열기 → 열기**
   - 맥 비밀번호를 물으면 입력 (쳐도 화면에 안 보이는 게 정상)
3. "✅ 설치 끝!"이 나오면 창 닫기

## 쓸 때
1. **`2_RAW영상공장_열기.command`** 더블클릭 → 브라우저에 화면이 뜸. 검은 창은 쓰는 동안 켜 두기 (닫으면 멈춤)
2. 탭 고르기 → 영상 끌어다 놓기 → 칸 채우기 → [만들기]
3. 오른쪽 '작업'에 진행 상황 → 끝나면 바로 미리보기 + [파인더에서 보기]
4. 결과: `동영상(Movies)/RAW 영상공장/날짜/` (확인 사진 포함). 올린 원본 복사본은 `.작업중` 폴더 (가끔 비워도 됨)

## 쌤 고르기 (단체 수업)
- 영상을 올리면 장면 사진이 나옴 → 슬라이더로 장면 옮기기 → **쌤을 클릭**(보라 동그라미)
- [이 장면을 시작으로]를 누르면 그 시각이 시작 초가 됨
- 결과와 같이 나오는 **확인 사진**에서 보라 상자가 계속 쌤인지 확인. 다른 사람이면 쌤이 혼자 잘 보이는 장면에서 다시 클릭
- 세로 영상(원장님이 편집한 세로본 등)은 따라가기 없이 그 구간만 씀

## 시작·끝 정하기 (2026-11-17)
- 슬라이더 아래 **◀ 1초 / ◀ 0.1 / 0.1 ▶ / 1초 ▶** 로 장면을 옮기고 **[▶ 여기부터]** · **[■ 여기까지]** → 시작 초·길이가 자동으로 들어감 ("시작 → 끝 (몇 초)" 표시)
- **[끝 장면 보기]** 로 끝나는 장면 확인
- TRACKPAD에서 춤 시작 후보를 누르면 끝(쌤이 노래를 다시 틀기 직전)까지 길이도 같이 들어감

## TRACKPAD 자막·로고 (2026-11-17)
- '자막 (춤 시작 전 몇 초)': 1~5초 (기본 5초). 춤 시작 전 그 시간 동안 자막이 나오고 춤 시작에 딱 사라짐. 짧게 고르면 글자 켜지고 꺼지는 속도가 알아서 빨라짐
- 자막 구간 소리: 연습실 원래 소리(카운트 등) → 노래가 시작되는 순간 깨끗한 음원으로
- 끝 로고: 춤이 끝난 뒤에도 영상이 계속 흐르면서 검은 화면 + RAW 로고가 덮음 → 음악이 끊기지 않고 이어지다가 마지막 1.5초에 작아짐

## LUT 화질 (2026-11-17 확인)
- LUT 자체는 화질을 깨지 않음 (8비트·16비트 계산 차이 약 45dB, 확대해도 구분 안 됨). 지금은 16비트로 계산 + 중간 파일 거의 무손실(crf 12) + 음원 입힐 때 영상은 다시 압축하지 않음
- 인스타에 올리면 인스타가 다시 압축하므로 그쪽 손실이 훨씬 큼

## 유튜브 이어붙이기 (2026-11-17)
1. 영상 여러 개를 한 번에 끌어다 놓기 (파일 이름 순서로 들어옴 → ▲▼로 순서 바꾸기, ✕로 빼기)
2. **1번 영상만** [장면 고르기]로 시작·끝 정하기 (춤 시작 자동 찾기도 됨)
3. **[🎵 1번과 같은 노래 구간으로 나머지 맞추기]** → 나머지 영상의 시작·길이가 같은 노래 구간으로 자동 (✓ 맞춤 / ⚠️ 못 찾음)
4. 쌤 솔로처럼 더 긴 영상은 그 영상 길이만 늘리기 → [만들기]
- 음원은 올려도 되고, 안 올리면 음원 폴더에서 같은 곡을 찾음. 디졸브 동안 소리도 자연스럽게 겹침
- 크기: 원본(4K면 4K, 유튜브 화질에 유리하지만 오래 걸림) / 1080p(빠르게)

## 춤 시작 자동 찾기 (2026-11-17)
- 영상을 올리고 **🎯 춤 시작 자동 찾기** → 1~2분 뒤 후보 사진이 나옴 → 사진을 누르면 시작 초가 들어가고 장면도 그리로 감
- 음원 폴더에 그 노래가 있으면: 쌤이 노래를 **처음부터 다시 튼 순간**을 정확히 찾음 (가장 정확)
- 없으면: 같은 구간 반복 · 노래가 시작되는 순간 · 움직임이 커지는 순간으로 후보를 냄 → 맞는 게 없으면 슬라이더로

## 음원 폴더 (2026-11-17)
- 위치: `음악(Music)/RAW 음원` (화면 오른쪽 위 **[음원 폴더 열기]**). 받은 음원(mp3·wav·m4a)을 그냥 넣어 두면 됨, 파일 이름은 아무거나
- 쌤 15초 · TRACKPAD · 음원 싱크에서 음원을 따로 안 올려도 **영상 속 노래와 같은 곡을 폴더에서 찾아** 깨끗한 음원으로 입힘
- 쌤 15초는 폴더에 같은 곡이 없으면 원래 소리 그대로 (실패하지 않음)
- 같은 곡이어도 스피드업·리믹스 버전은 못 맞춤 → 수업에서 튼 그 버전으로

## 음원 싱크가 "못 찾았어요"라고 할 때
- 영상 속 소리가 다른 노래거나(다른 홀 소리 등) 음원 버전이 다를 때 (스피드업·리믹스)
- 같은 노래를 여러 번 튼 긴 영상 → '쓸 구간 시작·끝'을 넣으면 그 안에서만 찾음
- 그래도 안 되면 '노래 0:00 = 영상 몇 초'를 직접 입력 (노래 첫 소리가 나오는 순간의 영상 시각)
- 결과 이름에 **⚠️ 음원 박자 확인필요**가 붙으면: 위치가 두 군데로 비슷하게 나온 것. 영상을 보고 박자가 어긋나면 작업 기록에 적힌 다른 후보 숫자를 '노래 0:00' 칸에 넣고 다시
- 쌤이 노래를 중간에 처음부터 다시 틀었으면, '노래 시작부터 자르기'를 켜 두면 다시 튼 순간부터 씀

## 만든 사람 메모 (Claude용)
- 춤 시작 `tools/class-reel/find_start.py`, 음원 맞추기 공통 `audiomatch.py`(music_sync.py·find_start.py가 같이 씀). 음원 폴더는 환경 변수 `RAW_MUSIC`로 바꿀 수 있음

- 맥 설치: Homebrew → node·ffmpeg·uv → `.venv` = uv가 받은 파이썬 3.12(`uv venv --managed-python`, Homebrew 파이썬은 macOS 26.2에서 맥 버전을 못 읽어 pip이 멈춤) + ultralytics, lap, flask, numpy → `npm install`(playwright) + `npx playwright install chromium` → `tools/fonts/install.sh`(맥은 ~/Library/Fonts)
- 스토리는 기존대로 `content/날짜_daily-story/story.mp4`를 만들고 결과 폴더로 복사. 대강·팝업은 `tools/daily-story/extra.json`에 저장 → 원장님 맥의 extra.json은 저장소와 따로 놀 수 있음 (Claude에게 부탁할 땐 바뀐 내용 알려 주기)
