날짜를 고르고 불러오기를 누르세요.

쌤 15초 (스토리 뒤에 올리는 영상)

영상 → 쌤 따라가며 세로로 → RAW 스타일 이름·장르·요일 + 끝 화면 2초. 단체 수업이면 사진에서 쌤을 눌러 주세요.

끝 화면 문구가 비면 '매주 요일 시간'으로 들어가요

TRACKPAD 릴스 (풀 안무)

춤 시작 전 몇 초 동안 TRACKPAD 자막(곡명 / 강사 / 장르) → 쌤 따라가며 춤 → 끝에 RAW 로고. 음원은 연습실 소리에 맞춰 깨끗한 음원으로 바꾸고, 로고가 나와도 음악은 이어져요.

음원 싱크

영상 속 연습실 소리와 음원을 비교해서 정확한 위치에 음원을 입혀요. 같은 노래를 여러 번 튼 영상이면 쓸 구간(시작·끝)을 꼭 넣어 주세요.

유튜브 이어붙이기 · 3분할

3분할: 영상 3개 = 1번 위 · 2번 가운데 · 3번 아래. 세 영상이 같은 노래 구간을 동시에 춰요 (프리미어에서 '오디오로 동기화' 후 위아래로 나누던 것과 같음). 음원이 없으면 1번 영상 소리로 맞춰요.

같은 곡·같은 구간을 A그룹 → B그룹 → 쌤 솔로 → 단체처럼 이어 붙여요. 가로 그대로, 영상마다 깨끗한 음원으로 맞추고 사이는 교차 디졸브.
1번 영상의 시작·끝만 정하고 [🎵 같은 구간으로 맞추기]를 누르면 나머지 영상은 자동으로 같은 노래 구간으로 잘려요.

영상 여러 개 — 눌러서 고르거나 끌어다 놓기 (순서는 아래 ▲▼로)

1번 영상 춤 시작 전 고른 초만큼 앞에서부터 쓰고, 그동안 자막 → 춤 시작에 딱 사라져요. 그 몇 초는 연습실 소리, 노래 시작부터 깨끗한 음원. 강사를 비우면 자막 없이.

LUT만 입히기

완성된 영상에 색감(LUT)만 입혀요. 강도 100% = 프리미어에서 그대로 입힌 것과 같아요.
