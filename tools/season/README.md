# RAW SEASON (전문반) — 학원 태블릿 한 대로 출석 + 순위표

태블릿 화면 = 순위표. 학생이 **내 이름 → 버튼(수업 출석 / 연습 시작 / 연습 끝 / 운동 완료 / 연습일지) → 비밀번호 4자리** → 구글 시트에 기록 → 화면 바로 갱신.
돈·서버 없음 (원장님 구글 계정 안에서 돌아감). 2026-11-10 원장님과 설계 (`content/2026-11-10_motivation-ideas/pro-season-plan.md`).

## 규칙 ([설정] 탭에서 숫자 바꿈, 2026-11-10 원장님 확정)
- 점수: 전문반 금요일 고정수업 20P · 그 밖의 수업 10P (수업마다, 하루 3번까지, 1시간 간격) · 개인연습 30분+ 10P · 운동 루틴 10P · 연습일지 10P (뒤 셋은 하루 1회)
- 연습 끝을 누를 때 '개인연습 / 월말평가 준비' 선택. 월말평가 준비는 기록만 (0P). 연습 끝을 안 누르면 그날 연습 불인정
- 운동·연습일지(수업정리)는 학원·집 상관없음 → 태블릿에서 '오늘 / 어제' 골라 체크 + 단톡방에 인증 (원장님 확인, 가짜면 [기록]에서 삭제)
- 🔥 연속 기록 = 금요일 전문반 고정수업 출석. 빠지면 0부터 (오늘 금요일은 수업 전까지 점선)
- 🛡 보호권 시즌 1장: 수업 전 보호자 연락을 받으면 원장님이 [학생] 탭 C열에 그 금요일 날짜(예 2026-11-20) 입력
- 포폴 영상 자격: 시즌 금요일 개근(보호권 포함) 전원
- 화면: 🔥 이어가는 중 / 💤 끊김 / 🛡 보호권, 금요일 도장(✓ · 🛡 · ✕ · ○), NOW 연습 중

## 설치 (처음 한 번, 10분)
1. 구글 드라이브 → 새 구글 시트 → 이름 `RAW SEASON 1`
2. **확장 프로그램 → Apps Script**
3. `Code.gs` 내용을 지우고 `tools/season/Code.gs` 전체 붙여 넣기
4. **+ → HTML** → 이름 `Board` → `tools/season/Board.html` 전체 붙여 넣기 → 저장
5. 함수 목록에서 `setup` → **실행** → 권한 허용 → [설정]·[학생]·[기록] 탭 생성 (시간대 서울로 맞춤)
6. [학생] 탭: A열 이름, B열 비밀번호 4자리(학생마다 다르게, 본인에게만 알려 줌)
7. **배포 → 새 배포 → 웹 앱** → 실행: 나 / 액세스: 나만 → 배포 → 주소 복사

## 갤럭시탭 세팅
1. 크롬을 원장님(학원) 구글 계정으로 로그인 → 배포 주소 열기 → 메뉴(⋮) → **홈 화면에 추가** (주소창 없이 열림)
2. 화면 꺼짐: 화면이 켜져 있게 페이지가 잡아 둠. 그래도 꺼지면 설정 → 디스플레이 → 화면 자동 꺼짐 최대
3. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → **앱 고정** 켜기 → 최근 앱에서 이 앱 고정 (학생이 못 나감)
4. 충전기 연결, 와이파이 연결. 연습실 입구에 세워 두기

## 운영
- 원장님: 보호권 날짜 입력, 가끔 [기록]과 단톡방·CCTV 맞춰 보기. 가짜 기록은 [기록]에서 그 줄 삭제
- 화면은 1분마다, 그리고 누가 체크할 때마다 새로 읽음
- 코드를 고친 뒤: Apps Script에 다시 붙여 넣고 **배포 → 배포 관리 → 수정 → 새 버전 → 배포** (주소 그대로)
- 미리보기(지어낸 예시 10명): `node tools/season/preview.js` → `content/2026-11-10_motivation-ideas/tablet-*.png`
