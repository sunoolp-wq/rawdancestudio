# RAW SEASON 랭크보드 (구글 시트 → 학원 TV)

선생님은 시트에 출석 체크만 → TV 화면이 점수·🔥연속 기록·티어·순위를 알아서 계산해 1분마다 갱신.
돈·서버 없음 (원장님 구글 계정 안에서 돌아감). 2026-11-10 예시 제작.

## 설치 (처음 한 번, 10분)
1. 구글 드라이브 → 새 구글 시트 → 이름 `RAW SEASON 1`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 왼쪽 `Code.gs` 내용을 지우고 `tools/season/Code.gs` 전체를 붙여 넣기
4. 왼쪽 **+ → HTML** → 이름 `Board` → `tools/season/Board.html` 전체를 붙여 넣기 → 저장
5. 위쪽 함수 목록에서 `setup` 선택 → **실행** → 권한 허용 → 시트에 [설정]·[출석]·[미션] 탭이 생김
6. [설정]에서 시즌 날짜·점수·티어 기준 확인, [출석] A·B열에 학생 이름·반 입력
7. **배포 → 새 배포 → 유형 웹 앱** → 실행: 나 / 액세스: 나만 → 배포 → 나온 주소를 학원 TV 브라우저에서 열고 전체 화면(F11)
   - TV 브라우저가 원장님 구글 계정으로 로그인돼 있어야 함 (액세스 '나만'이라 밖에서는 못 봄)

## 매일
- 선생님: [출석] 탭 오늘 날짜 칸 체크 (휴대폰 구글 시트 앱 가능)
- 미션(셀프캠·사이퍼·팝업·공연): [미션] 탭에 날짜·이름·미션 한 줄
- TV: 그대로 켜 두면 됨 (1분마다 새로 읽음, 순위는 8초마다 다음 10명)

## 계산 규칙 ([설정] 탭에서 바꿈)
- 출석 1회 10P (같은 날 여러 수업은 1회) / 2주 연속부터 매주 +5P / 미션 점수
- 🔥 연속 기록 = 매주 1번 이상 온 주가 몇 주 이어졌는지. 이번 주 아직 안 왔으면 지난주까지 기록 유지 + 아래 흐르는 줄에 "이번 주 오면 이어져요"
- 티어: ROOKIE 0 → CREW 60 → CORE 150 → RAW 250
- 흐르는 줄: 1위 / 이번 주 승급자 / 기록 끊기기 직전 학생

## 코드를 고친 뒤
- Apps Script에 다시 붙여 넣고 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (주소는 그대로)
- 미리보기(예시 데이터): `node tools/season/preview.js 2026-12-10` → `content/2026-11-10_motivation-ideas/rankboard-preview.png`
